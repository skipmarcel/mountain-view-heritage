# Mountain View Heritage — website

React + Vite. Pages: Home, Education, Events, Calendar, Contact.

## Run it

1. Install [Node.js](https://nodejs.org) (v18 or newer).
2. Open this folder in VS Code, then in the terminal:

```
npm install
npm run dev
```

3. Open the local address it prints (usually http://localhost:5173).

`npm run build` creates a `dist/` folder ready to upload to any static host (Netlify, Vercel, etc.).

## Where things live

- `src/config.js` — brand settings: accent color, font pairing, button radius, hero video timing, hero logo size/opacity, color or black & white photos.
- `src/data/content.js` — all page copy and lists (offerings, courses, events, photos).
- `src/data/pcc-classes.json` — Calendar page classes, generated by `scripts/scrape-pcc.mjs`. Don't edit by hand.
- `src/components/` — Header (nav), Hero (crossfading video), PageBanner (inner-page photo header), Footer.
- `src/pages/` — one file per page.
- `src/styles/modernist.css` — design-system tokens and component classes (`.btn`, `.field`, `.input`, `.tag`).
- `src/styles/global.css` — resets and hover states.
- `public/videos/` — the four hero clips. `public/assets/` — logos and photos.

## Notes

- The Calendar page lists the "Butchering for the Home Chef" classes from PCC's schedule (https://www.pcc.edu/schedule/fall/coo/, plus the winter/spring/summer pages when posted). `npm run build` re-scrapes them first; run `npm run scrape` to refresh on its own. If PCC can't be reached, the build keeps the last saved list. The site only picks up PCC changes when it is rebuilt, so schedule a regular rebuild on your host (e.g. a daily Netlify/Vercel build hook). Past dates are hidden automatically.
- The contact and mailing-list forms only show a confirmation; connect them to a form service or backend.
- The hero videos total about 34 MB. Compress them (e.g. with HandBrake, 1080p, ~2–4 MB each) before going live.
